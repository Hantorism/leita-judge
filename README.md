# leita-judge

## Git Commit Message Convention
| Type | Description |
|------|------|
| feat | 새로운 기능 추가 |
| fix | 버그 수정 |
| refactor | 코드의 로직 변경, 기능 개선 |
| delete | 코드나 파일 삭제 |
| move | 파일 이동, 파일명/디렉터리명 변경 |
| test | 테스트/벤치마크 |
| style | 변수명/함수명 변경, 코드 포맷 변경 |
| design | UI 디자인 변경 |
| deploy | 배포 관련 작업 |
| docs | 문서 관련 작업 |
| chore | 기타 |
